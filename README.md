# TEEROP POS — Multi-Category POS & Inventory Management System

A full-stack Point-of-Sale (POS) and Inventory Management System developed as the final capstone project for the TEEROP Web Development Internship.

## Project Status

Phase 1 — Planning & Setup

## Technology Stack

### Frontend
- React
- Tailwind CSS
- React Router
- Axios

### Backend
- Node.js
- Express.js

### Database
- PostgreSQL
- Sequelize

### Authentication
- JWT
- bcrypt

### File Upload
- Multer

### Deployment
- Render
- Vercel

### AI Development
- Kiro / Antigravity

## User Roles

### Admin
Full system management and store-wide reporting.

### Inventory Manager
Product, inventory, category, stock and low-stock management.

### Cashier
POS billing, checkout and personal transaction history.

## Development Phases

1. Planning & Setup
2. Backend Core
3. Authentication
4. Inventory Module
5. Billing / POS
6. Frontend
7. Statistics, Polish & Deployment
